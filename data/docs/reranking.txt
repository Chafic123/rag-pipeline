What is reranking?

Retrieval quality improves with a second stage called reranking. The first stage, vector search, uses a bi-encoder: the question and each chunk are embedded separately and compared, which is fast because chunk vectors are computed once. Its weakness is that the model never reads the question and chunk together. A reranker is a cross-encoder: it takes the question and one chunk as a single input and outputs a relevance score, which is far more accurate but too slow to run over a whole database. So the pipeline retrieves perhaps the top twenty candidates with the fast bi-encoder, then the cross-encoder rescores just those and keeps the best few. Hybrid search is a different improvement to the first stage: it combines keyword matching, often BM25, with vector similarity, so exact terms and meaning both count.
