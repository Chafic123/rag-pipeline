How do you evaluate a RAG system?

Evaluating a RAG system means measuring it against a fixed set of questions whose correct answers are known in advance. This set is the ground truth. The first metric is hit-rate at k, which asks whether the correct chunk appears among the top k retrieved results, and it measures retrieval alone. Because retrieval sets a ceiling on the whole system, if the right chunk is never retrieved the model cannot answer, evaluation usually starts there. Faithfulness measures whether the generated answer is supported by the retrieved context rather than invented. When there is no labelled answer, an LLM-as-judge can score responses by prompting a second model to grade them. Frameworks such as RAGAS and Promptfoo automate these metrics so every change can be measured instead of guessed.
