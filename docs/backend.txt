What is a backend?

The backend is the part of an application users never see. It stores data, enforces business logic, handles authentication, and integrates with other systems. Reliability is the backend's first job: it must stay fast and correct even under heavy load. Latency is how long a single request takes, and throughput is how many requests it can serve per second. Engineers watch the p99 latency, the time under which the slowest one percent of requests complete, because averages hide the worst cases. A database connection pool reuses a fixed set of open connections so each request does not pay to open a new one. Caching stores the result of expensive work so repeated requests are cheap. Load testing, sending many simulated requests at once, reveals where a system breaks before real users do.
