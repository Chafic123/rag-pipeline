What is an API?

An API, or application programming interface, is a contract between two programs. A REST API exposes resources through endpoints, and clients send requests using HTTP methods: GET to read, POST to create, PUT to replace, and DELETE to remove. The server answers with a status code. A 200 means success, a 404 means the resource was not found, and a 500 means the server itself failed. Responses are usually encoded as JSON. Good API design keeps endpoints predictable, versions them so old clients keep working, and documents them with an OpenAPI or Swagger specification. Rate limiting protects an API from being overwhelmed by too many requests, and authentication decides who is allowed to call it. These interfaces are how services, mobile clients, and increasingly AI systems talk to a backend.
